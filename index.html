How the TikTok integration works

1

OAuth Authorization

The account owner authenticates once via TikTok's OAuth 2.0 PKCE flow. An access token and refresh token are stored locally and refreshed automatically.

2

Video Upload (Content Posting API)

Once a video is generated, it is uploaded to TikTok via the Content Posting API using the video.upload and video.publish scopes. The video is posted directly to the creator's profile.

3

Publish Confirmation

The API returns a publish_id. The system polls the status endpoint until PUBLISH_COMPLETE is confirmed, then logs the result.

4

Profile Info (user.info.basic)

The user.info.basic scope is used to verify the authenticated account's identity and display name before publishing.
