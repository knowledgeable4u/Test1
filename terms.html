Knowledgeable4u operates a private content automation system that generates and publishes short-form educational videos about neuroscience, biohacking, and health science to TikTok. This is a single-operator, private-use platform. It is not a public-facing multi-user service.

2. TikTok API Usage

Our platform uses the following TikTok Developer API products and scopes:

  • Login Kit — for authenticating the account owner via TikTok OAuth 2.0
  • Content Posting API — for uploading and directly publishing video content to our TikTok profile
  • user.info.basic — to retrieve the authenticated user's display name and open_id for identity verification
  • video.upload — to upload video files to TikTok
  • video.publish — to directly publish uploaded videos to our TikTok creator profile

All API usage complies with TikTok's Developer Terms of Service and App Review Guidelines.
